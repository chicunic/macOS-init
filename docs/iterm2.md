# iTerm2

## Sync Settings

Settings -> General -> Settings, check Load settings from a custom folder or URL, set path to:

```text
iCloud Drive/iterm2
```

## Manual Configuration

### General

- Closing -> Check Quit when all windows are closed

- Selection -> Uncheck Clicking on a command selects it to restrict Find and Filter

- Window -> New window placement -> Remember the position of previously closed windows and use size from profile

- AI -> General -> Check Enable generative AI features, AI Model -> Always use the recommended model from Gemini

- Software Update -> Check Ignore non-critical shell integration updates

### Profiles

- Colors -> Uncheck Use separate colors for light and dark mode, Color Presets -> Dark Background

- Text -> Font -> MesloLGS NF, Regular, 13

- Session -> Prompt before closing -> Never
