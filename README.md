A setup guide for a new Mac with Apple Silicon and macOS Tahoe 26.

## Setup Guides

Follow the guides in order. Pick the tools and settings you need.

| Doc | Description |
| --- | --- |
| [macOS](docs/macos.md) | Dock, screenshots, Finder, system settings |
| [Xcode](docs/xcode.md) | Xcode app and standalone Command Line Tools |
| [Homebrew](docs/homebrew.md) | Package installation, configuration, maintenance |
| [Fonts](docs/fonts.md) | CJK and programming fonts |
| [iTerm2](docs/iterm2.md) | Settings sync, profiles, AI |
| [Oh My Zsh](docs/oh-my-zsh.md) | Plugins, Powerlevel10k, shell configuration |
| [GitHub](docs/github.md) | Key restoration, CLI login, commit signing |

## Configuration Files

- [zshrc](powerlevel10k/zshrc) -> `~/.zshrc`
- [p10k.zsh](powerlevel10k/p10k.zsh) -> `~/.p10k.zsh`

Copy commands: [Oh My Zsh quick setup](docs/oh-my-zsh.md#quick-setup).
